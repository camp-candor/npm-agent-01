### 4. Negative-Control Assertions & Boundary Verification

1. **Precedence Dominance Negative Control:**

- Setting
  `(global as any).agentBaseUrl = '[http://127.0.0.1:8787](http://127.0.0.1:8787)'`
  immediately overrides `(global as any).packageBaseUrl`,
  `process.env.LIVE_WORKER_URL`, and fallback staging URLs. Calls to
  `getBaseUrl()` reflect loopback port 8787 within the same event tick.

2. **Fallback Progression Negative Control:**

- Deleting `(global as any).agentBaseUrl` and `(global as any).packageBaseUrl`
  causes `getBaseUrl()` to fall back through ambient environment variables down
  to the canonical staging root without throwing null reference or invalid URL
  exceptions.

3. **Trailing Slash Path Pollution Negative Control:**

- Passing `[http://127.0.0.1:8787///](http://127.0.0.1:8787///)` or
  `[https://edge.workers.dev//](https://edge.workers.dev//)` through
  `getBaseUrl()` returns strictly sanitized strings with no trailing slashes.
  String concatenation to `${getBaseUrl()}/health` evaluates to
  `[http://127.0.0.1:8787/health](http://127.0.0.1:8787/health)`, eliminating
  gateway 404 double-slash errors.

4. **WebSocket Scheme Derivation Negative Control:**

- Passing an unencrypted loopback URL
  (`[http://127.0.0.1:8787](http://127.0.0.1:8787)`) to `getBaseWsUrl()` returns
  `ws://127.0.0.1:8787`.

- Passing a TLS-secured edge endpoint
  (`[https://npm-agent-01-staging.berad4000.workers.dev](https://npm-agent-01-staging.berad4000.workers.dev)`)
  returns `wss://npm-agent-01-staging.berad4000.workers.dev`.

5. **Process Timeout & Rollback Negative Control:**

- Simulating an un-routable local port in `toggleTargetMode` results in 15
  failed polling attempts. The switchboard aborts, terminates the child process
  tree via `taskkill` (Win32) or `SIGTERM` (POSIX), reverts internal state to
  `LIVE`, deletes `(global as any).agentBaseUrl`, and logs diagnostic stderr
  details to console `cns00` without hanging the TUI event loop.
